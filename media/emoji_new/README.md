# Новые иконки TwinLove

Черновой набор для обычных emoji, которые ещё встречаются в интерфейсе бота. Файлы PNG имеют размер 100×100 пикселей и прозрачный фон. Цвета повторяют `media/emoji`: бирюзовый силуэт смещён вверх и влево относительно малинового. Между ними оставлен прозрачный зазор; глаза и рот нарисованы заполненными бирюзовыми деталями. Иконки из этой папки пока не подключены к боту и не загружены в Telegram.

Скрепка 📎 уже перенесена в `media/emoji/attachment.png`. Обе линии тонкие; бирюзовая слегка расширяется от нижнего левого начала к верхнему округлённому концу. Между цветами остаётся прозрачный зазор. Линия идёт вдоль внешнего изгиба, чтобы не сливаться со значком ссылки `link.png`.

Для 🔍, 🔄, 🔒 и 👋 исходные векторные рисунки лежат в `svg/`. Сердце ❤️ сделано из символа в `media/emoji/logo.png`, без нижних точек. 🌆 и 🔍 уже лежат в `media/emoji/`; остальные иконки из списка пока остаются здесь для просмотра.

Силуэт 👋 адаптирован из [Font Awesome Free Solid hand](https://github.com/FortAwesome/Font-Awesome/blob/7.x/svgs/solid/hand.svg) (CC BY 4.0): рука повернута, добавлено фирменное бирюзовое смещение с прозрачным зазором. Атрибуция также сохранена в `svg/wave.svg`.

✍️ больше не используется в интерфейсе: в личных сообщениях его заменил карандаш ✏️ из `TwinLoveEmoji`, в канале остаётся обычный ✏️.
